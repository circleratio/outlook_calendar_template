# 要求仕様: Outlook 予定表テンプレートアドイン

## 概要

新しい Outlook（Windows 版の新しい Outlook / Outlook on the web。Classic Outlook は対象外）で使う予定表アドイン。
予定表で選んだ日時に対し、あらかじめ登録しておいた「イベントテンプレート」（件名・本文・出席者・場所・会議時間・公開範囲・カテゴリ）を選ぶだけで適用し、会議開催通知の作成を効率化する。

## 前提・技術的制約

- アドインは Office アドイン（Office.js を使う Web アドイン）として作る。新しい Outlook は COM/VSTO アドインに対応していない。
- アドインから予定表グリッドで選んだ日時を直接取得する API は存在しない。そのため、日時の選択は「新しいイベント作成フォームを開く」ことで行い、アドインはフォームから開始・終了日時を読み取る。
- 会議開催通知の送信は Outlook 標準の［送信］ボタンで行う（アドインからは送信しない）。
- Office.js のみで実現し、Microsoft Graph API や Entra ID のアプリ登録は使わない。

## 要求仕様

### 起動

- 予定（Appointment）作成フォーム（開催者モード／Appointment Organizer）のリボンにアドインのコマンドボタンを表示する。
- 開催者として開いた既存のイベントでも、同じようにテンプレートを適用できる。更新通知の送信は Outlook 標準の動作に任せる。
- ボタンを押すと作業ウィンドウ（Task Pane）が開く。

### テンプレートの適用

- 作業ウィンドウに登録済みテンプレートを一覧表示し、ユーザーが 1 件を選んで［適用］を押す。
- 適用内容（テンプレートで設定する項目）:

| 項目 | 適用時の動作 |
|---|---|
| 件名 | 上書き |
| 本文 | 既存の本文の先頭に挿入（署名など既存の本文は残す） |
| 場所 | 上書き |
| 公開範囲 | 「公開」または「非公開」を指定した場合は上書き。「変更しない」の場合はフォームの値を変更しない |
| カテゴリ | 既存のカテゴリに追加（重複する名前は追加しない）。テンプレートで空欄の場合は変更しない |
| 必須出席者 | 既存の出席者に追加（重複アドレスは追加しない） |
| 任意出席者 | 既存の出席者に追加（重複アドレスと、必須出席者に含まれるアドレスは追加しない） |
| 会議時間（分） | 開始日時はフォームの値をそのまま使い、終了日時 = 開始日時 + 会議時間 に設定する。テンプレートで未設定の場合は終了日時を変更しない |

- テンプレートで空欄の項目（件名・本文・場所）は、フォームの値を変更しない。
- 同じフォームに再度適用すると、本文はその都度先頭に挿入される（前回挿入した本文は自動では削除しない）。出席者も追加のみで、前回追加した出席者は自動では削除しない。
- 終日イベントには会議時間を適用せず、終了日時を変更しない。`{開始時刻}` と `{終了時刻}` はフォームの値（`00:00`）に置き換える。Office.js に終日かどうかを取得する正式な API がないため、開始と終了がともに 0:00 で日付が異なるイベントを終日イベントとして扱う。
- 重複アドレスは大文字・小文字を区別せずに判定する。フォームの任意出席者にすでにいる人をテンプレートの必須出席者に追加する場合、任意出席者からは削除しない。
- 場所は文字列として設定する（会議室の予約は行わない）。
- 適用が終わったら、作業ウィンドウに完了メッセージを表示する。ユーザーは内容を確認・修正し、［送信］で会議開催通知を発行する（出席者がいない場合は［保存］で保存する）。

### 差し込み（プレースホルダー）

- 件名と本文では、以下のプレースホルダーを適用時の日時に置き換える。日時はメールボックスのタイムゾーンで表示する。

| プレースホルダー | 置き換え例 |
|---|---|
| `{日付}` | `2026/11/05(木)` |
| `{開始時刻}` | `10:00` |
| `{終了時刻}` | `11:00`（会議時間を適用した後の終了時刻） |

- `{日付}` は開始日に置き換える。日付をまたぐ会議でも `{終了時刻}` は時刻だけを表示する。
- 置き換えは適用時に一度だけ行う。適用後にフォームで日時を変えても、件名・本文は自動では更新されない。

### テンプレートの管理（個人用）

- テンプレートはユーザーごとに登録する（組織共通のテンプレートは持たない）。
- 作業ウィンドウ内の編集画面で、テンプレートの新規作成・編集・削除を行う。
- テンプレートの項目: テンプレート名（必須・50 文字以内・重複不可。一覧に表示）、件名、本文、場所、必須出席者、任意出席者、会議時間（分。1〜1440 の整数、空欄可）、公開範囲（変更しない・公開・非公開。既定は変更しない）、カテゴリ（複数可、空欄可）。
- 公開範囲とカテゴリを追加する前に保存したテンプレートは、公開範囲を「変更しない」、カテゴリを空欄として扱う。
- カテゴリは Outlook のカテゴリ一覧にある名前を入力する。カンマ・セミコロン・改行で区切る。一覧からの選択や、一覧にないカテゴリの自動作成は行わない（`ReadWriteMailbox` 権限が必要になるため）。保存時には名前が一覧にあるかを確認せず、設定できない場合は適用時のエラーとして表示する。
- テンプレート名以外の項目がすべて空の場合は保存できず、エラーを表示する。
- 一覧は保存順に表示する（新規作成は末尾に追加）。
- 本文はプレーンテキストで入力する（改行を保持して設定する）。
- 出席者はメールアドレスで入力する。形式が不正なアドレスがあると保存できず、エラーを表示する。
- 保存先は Office.js の `roamingSettings` とする。同じユーザーが別の端末で開いても同じテンプレートを使える。
- `roamingSettings` の容量上限（約 32KB）に余裕を持たせ、テンプレート全体のデータが保存時の形式で 30,000 バイトを超える場合は、保存せずにエラーを表示する。ただし、すでに超えているデータを減らす保存は許可する。
- 複数の端末やウィンドウで同時に編集した場合は、後から保存した内容が優先され、先に保存した変更は失われる（個人での使用を前提に許容する）。

### 異常系

- テンプレートが 1 件もない場合は、一覧の代わりに「テンプレートを作成してください」という案内と作成ボタンを表示する。
- フォームの開始・終了日時を取得できない場合は、エラーメッセージを表示し、どの項目も設定せずに中断する。
- フォームへの設定に失敗した場合（API エラーなど）は、失敗した項目名を含むエラーメッセージを表示する。それまでに設定できた項目は元に戻さない。
- 保存済みテンプレートを読み込めない場合（データの破損、未知の形式）は、警告を表示し、テンプレートの保存を禁止する。既存データを上書きしないよう、新規作成の操作も表示しない。
- この状態から復旧するために［初期化］ボタンを表示する。確認を経て保存済みのデータをすべて削除し、テンプレートが 0 件の状態に戻す。

### 配布・動作環境

- 対象クライアント: Windows 版の新しい Outlook、Outlook on the web。
- 配布: 個人でのサイドロード（`https://aka.ms/olksideload` で開く「Add-Ins for Outlook」ダイアログの「My add-ins」→「Add a custom add-in」）。組織への一括展開は対象外。
- アドインの Web 資産は HTTPS でホストする必要がある。開発中は `https://localhost:3000`、本番は GitHub Pages でホストする（詳細は [spec.md](spec.md)）。

### 対象外

- 繰り返し予定（定期イベント）への適用。動作は保証しない
- Teams 会議の自動付与、アラーム、添付ファイルの設定
- 会議室の予約、テンプレートの並べ替え
- 組織共通テンプレート、テンプレートの JSON インポート/エクスポート
- 開いているイベントからのテンプレート作成
- 会議開催通知の自動送信
- Classic Outlook、Mac 版 Outlook、モバイル版 Outlook

## 使いかた

1. 予定表で日時（時間帯）を選び、ダブルクリックなどで新しいイベントの作成フォームを開く。
2. 作成フォームのリボンにあるアドインのボタンを押し、作業ウィンドウを開く。
3. 作業ウィンドウの一覧からテンプレートの種類を選び、［適用］を押す。
4. テンプレートに登録した件名・本文・場所・出席者・会議時間がフォームに設定される。

   例: テンプレート「定例会議」（件名 `{日付} 定例会議`、会議時間 60 分、必須出席者 `a@example.com`）を、2026/11/05 10:00 開始のフォームに適用すると、次のようになる。

   ```
   件名:       2026/11/05(木) 定例会議
   開始:       2026/11/05 10:00
   終了:       2026/11/05 11:00
   必須出席者: a@example.com（既存の出席者に追加）
   ```

5. 内容を確認し、Outlook の［送信］を押して会議開催通知を発行する（出席者がいない場合は［保存］を押す）。

### テンプレートの登録

1. イベントの作成フォームでアドインのボタンを押して作業ウィンドウを開き、［テンプレート管理］を開く。
2. ［新規作成］でテンプレート名と各項目を入力し、［保存］を押す。
3. 一覧から既存のテンプレートを選んで編集・削除する。
