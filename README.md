# Outlook 予定表テンプレートアドイン

新しい Outlook の予定作成フォームに、登録しておいた「イベントテンプレート」（件名・本文・場所・出席者・会議時間）をワンクリックで適用する Office アドインです。定例会議などの会議開催通知を作る手間を減らします。

- テンプレートはユーザーごとに `roamingSettings` に保存するため、同じユーザーなら別の端末でも使えます（容量の上限は約 32KB）。
- Office.js だけで動作します。Microsoft Graph API や Entra ID のアプリ登録は不要です。
- 会議開催通知の送信は Outlook 標準の［送信］ボタンで行います。アドインからは送信しません。

## 必要環境

| 項目 | 内容 |
|---|---|
| 対象クライアント | Windows 版の新しい Outlook、Outlook on the web（Classic Outlook とモバイル版は対象外） |
| 開発環境 | Node.js 24 / npm 12（動作確認済みのバージョン） |

## インストール

アドインはサイドロードで個人のメールボックスに登録します。組織への一括展開には対応していません。

### 開発用（localhost）

1. 依存パッケージと、開発サーバー用の HTTPS 証明書をインストールします。証明書のインストール時に確認ダイアログが表示されます。

   ```powershell
   npm install
   npx office-addin-dev-certs install
   ```

2. 開発サーバーを起動します（`https://localhost:3000`）。アドインを使っている間は起動したままにします。

   ```powershell
   npm run dev-server
   ```

3. ブラウザーで <https://aka.ms/olksideload> を開きます。Outlook on the web が開き、しばらくすると「Add-Ins for Outlook」ダイアログが表示されます。
4. ダイアログで次の順に選び、リポジトリ直下の `manifest.xml` を登録します。

   1. **My add-ins**（個人用アドイン）
   2. ダイアログ下部の **Custom Addins**（カスタムアドイン）にある **Add a custom add-in**（カスタムアドインを追加）
   3. **Add from File**（ファイルから追加）

登録したアドインは、新しい Outlook アプリにも表示されます。Outlook アプリのメニューには、カスタムアドインを追加する項目がありません。

ダイアログや **Custom Addins** の欄が表示されない場合は、別のブラウザーかシークレットウィンドウで試してください。それでも表示されない場合は、組織の設定でサイドロードが制限されている可能性があるので、管理者に確認してください。

### 本番用（GitHub Pages）

公開済みのアドインを使う場合は、開発サーバーや証明書は不要です。

1. <https://circleratio.github.io/outlook_calendar_template/manifest.xml> をファイルとしてダウンロードします。
2. 開発用のアドインを登録済みの場合は先に削除します（「Add-Ins for Outlook」ダイアログの **Custom Addins** で、対象の「…」から **Remove** を選びます）。
3. 開発用と同じ手順で、ダウンロードした `manifest.xml` を登録します。

`main` ブランチにプッシュすると、GitHub Actions がテストとビルドを実行し、GitHub Pages に自動で公開します。別の場所に公開する場合は、`webpack.config.js` の定数 `urlProd` を書き換えてください。

## 使いかた

### テンプレートを登録する

1. 新しいイベントの作成フォームを開き、リボンの［テンプレート］ボタンを押して作業ウィンドウを開きます。
2. ［テンプレート管理］→［新規作成］で各項目を入力し、［保存］を押します（テンプレートが 1 件もないときは、最初の画面に［新規作成］が表示されます）。
3. 既存のテンプレートは、［テンプレート管理］の一覧から編集・削除できます。

| 項目 | 入力内容 |
|---|---|
| テンプレート名 | 必須。50 文字以内で、他のテンプレートと重複しない名前 |
| 件名・本文 | 差し込み（後述）が使えます。本文はプレーンテキストです |
| 場所 | 任意 |
| 必須出席者・任意出席者 | メールアドレス。カンマ、セミコロン、改行で区切ります |
| 会議時間（分） | 1〜1440 の整数。空欄可 |

### テンプレートを適用する

1. 予定表で日時を選び、新しいイベントの作成フォームを開きます。
2. リボンの［テンプレート］ボタンを押します。
3. 作業ウィンドウでテンプレートを選び、［適用］を押します。
4. フォームの内容を確認して、Outlook の［送信］を押します。

たとえば、テンプレート「定例会議」（件名 `{日付} 定例会議`、会議時間 60 分、必須出席者 `a@example.com`）を、2026/11/05 10:00 開始のフォームに適用すると次のようになります。

```
件名:       2026/11/05(木) 定例会議
開始:       2026/11/05 10:00
終了:       2026/11/05 11:00
必須出席者: a@example.com（既存の出席者に追加）
```

適用時の各項目の動作は次のとおりです。

| 項目 | 動作 |
|---|---|
| 件名・本文・場所 | 上書きします。テンプレート側が空欄なら変更しません |
| 必須出席者・任意出席者 | 既存の出席者に追加します。同じアドレスは重複して追加しません |
| 会議時間 | 終了日時を「開始日時 + 会議時間」に設定します。空欄なら変更しません |

一部の項目を設定できなかった場合は、その項目名をエラーとして表示し、残りの項目の設定を続けます。設定済みの項目は元に戻しません。

### 差し込み

件名と本文では、次のプレースホルダーを使えます。

| プレースホルダー | 置き換え例 |
|---|---|
| `{日付}` | `2026/11/05(木)` |
| `{開始時刻}` | `10:00` |
| `{終了時刻}` | `11:00`（会議時間を適用した後の終了時刻） |

日時はメールボックスのタイムゾーンで表示します。置き換えは適用時に一度だけ行うため、適用後にフォームで日時を変えた場合は、件名と本文を手動で修正するか、テンプレートを適用し直してください。

### 対応していない機能

- Teams 会議の自動付与、分類項目、アラーム、添付ファイルの設定
- 組織共通のテンプレート、テンプレートの JSON インポート/エクスポート
- 開いているイベントからのテンプレート作成

## 開発

Windows では、コマンドを PowerShell で実行してください。環境によっては Git Bash に `node` / `npm` の PATH が通っていません。

| コマンド | 内容 |
|---|---|
| `npm run dev-server` | `https://localhost:3000` で開発サーバーを起動する |
| `npm run build` | `dist/` に本番用ファイルを出力する |
| `npm test` | Jest でテストを実行する |
| `npm run typecheck` | TypeScript の型チェックを実行する |
| `npm run validate` | `manifest.xml` を検証する |

自動テストの対象は `src/core/` と `src/app/` です。`src/office/` と `src/taskpane/` は対象外なので、実際の Outlook で動作を確認してください。確認項目は [doc/plan.md](doc/plan.md) の S8 にあります。
